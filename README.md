# EPGURU

Обработка EPG по шаблонам без ИИ. Правила лежат в `templates/*.yaml`, движок — в `epg_processor.py`.
Шаблон выбирается автоматически по имени файла.

**Входные форматы** (тип определяется по содержимому, а не по расширению): XLSX/XLSM/XLTX, XLS (Excel 97–2003), XML (Excel 2003 SpreadsheetML и любой табличный XML), ODS, CSV/TSV/TXT (разделители `; , таб |`, кодировки UTF-8 и Windows-1251), HTML-таблицы, в том числе HTML, сохранённый как `.xls`. Результат всегда в XLSX.

| Шаблон | Каналы | Файл |
|---|---|---|
| MAKE SENSE | PLAN B, 9-1-1, VESNA | `templates/make_sense.yaml` |
| FIGHT CLUB | FIGHT CLUB | `templates/fight_club.yaml` |

Исходные текстовые правила лежат в `docs/`.

## Веб-сервис
Пульт в браузере: перетащил EPG и получил готовый файл. Есть очередь с историей, починка дат и вход по паролю.
Разворачивание на сервере описано в [DEPLOY.md](DEPLOY.md) (Docker; Cloudflare Tunnel + Access или Caddy).

Локально:

    pip install -r requirements-dev.txt
    EPGURU_PASSWORD=test EPGURU_SECURE_COOKIE=0 uvicorn server.main:app --reload

## Командная строка
    python epg_processor.py "EPG PLAN B 09.11-15.11.xlsx" "FIGHT CLUB EPG 09_11 - 15_11.xlsx" -o output
    python fix_dates.py файл.xlsx папка/ -o fixed

`fix_dates.py` приводит даты текстом и числом к DD/MM/YYYY и исправляет перепутанные день и месяц: неделю берёт из имени файла и сверяет с ней.

## Каталоги контента
Для каналов 9-1-1, VESNA и PLAN B EPG сверяется с каталогом. Каталог PLAN B — один лист «КАТАЛОГ» со столбцом «Тип» (фильм/сериал), его можно править прямо в Excel. Каталог загружается на сайте клавишей **КАТАЛОГ**, новый файл заменяет старый.
- Название найдено в каталоге как фильм — в «Формат» ставится `х/ф`, как сериал — `сериал`.
- Названия, которых нет в каталоге, перечисляются в логе вместе с похожими вариантами.
- Какие листы каталога содержат фильмы, а какие сериалы, описано в `templates/make_sense.yaml` в блоке `catalogs`.

Для всех каналов MAKE SENSE работает и чистка «пустых» названий серий: «1 серия», «Эпизод 3», «Серия №2», «Сезон 1. Серия 4» удаляются, а «Эпизод 3. Татьяна» остаётся как есть.

Из командной строки: `python epg_processor.py файл.xlsx --catalogs папка_с_каталогами` (файлы `911.xlsx`, `VESNA.xlsx`).

## Как поменять правила
- **Поменять значение** (новая замена, другое название столбца, новый канал): правьте YAML прямо на GitHub.
- **Новый формат:** скопируйте YAML, поменяйте `channels`, `rules` и `output_name`.
- **Новая операция:** добавьте блок `elif t == "..."` в `process_sheet` и тест в `tests/`.

После каждого коммита GitHub прогоняет тесты (`.github/workflows/test.yml`). Красный крестик в репозитории означает, что правка что-то сломала.

## Доступные правила
| type | что делает |
|---|---|
| `drop_columns_prefix` | удаляет столбцы, заголовок которых начинается с префикса |
| `time_floor` | округляет время вниз до N минут |
| `date_format` | приводит даты к DD/MM/YYYY (день первым) |
| `rebuild_dates` | пересчитывает даты от даты из имени файла, переход через полночь даёт +1 день; хвост прошлых суток в начале файла (с `previous_day_from`, в шаблоне FC — 22:00) получает дату предыдущего дня |
| `dedupe_consecutive` | удаляет только подряд идущие дубли (кроме указанных столбцов) |
| `replace_exact` | точная замена значений |
| `age_rating` | первое число из значения + «+» |
| `append_suffix` | дописывает суффикс, если его нет |
| `clear_if_equal` | очищает ячейку, если она совпадает с другим столбцом |
| `catalog_format` | ставит формат по каталогу канала (фильм/сериал) |
| `clean_episode_name` | очищает названия серий вида «1 серия», «Эпизод 3» |
