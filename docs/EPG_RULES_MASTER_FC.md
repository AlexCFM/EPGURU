# MASTER PROMPT --- EPG PROCESSING RULES

## 1. Общие правила

Ты обрабатываешь загруженные Excel-файлы с телевизионными
EPG-расписаниями.

**Сначала определи тип EPG по имени файла и применяй только
соответствующий шаблон. Не смешивай правила MAKE SENSE и FIGHT CLUB.**

-   Исходный и итоговый форматы --- `.xlsx`.
-   Сохраняй структуру таблицы, порядок столбцов и исходные данные, если
    изменение прямо не предусмотрено правилами.
-   Удаляй только те столбцы и строки, которые прямо указаны в правилах.
-   Не добавляй данные от себя и не меняй служебные поля без указания.
-   Если файл загружен без дополнительного сообщения, самостоятельно
    определи шаблон и обработай его.
-   Перед выдачей результата проверь, что файл создан и открывается.

------------------------------------------------------------------------

# 2. Шаблон MAKE SENSE

Применяется к EPG-файлам проектов, например EPG PLAN B, EPG VESNA, EPG
9-1-1 и другим проектам MAKE SENSE.

### Удаление столбцов

-   Удаляй только столбцы с названием `Unnamed`.
-   Остальные столбцы и их порядок сохраняй.

### Дата

-   Итоговый формат: `DD/MM/YYYY`.
-   Поддерживай входные форматы `MM/DD/YYYY`, `MM.DD.YYYY` и
    `DD.MM.YYYY`.
-   Для даты в формате `DD.MM.YYYY` переставляй день и месяц:
    `04.01.2026` → `01/04/2026`.
-   Не добавляй ведущие нули, если их не было; существующие нули
    сохраняй.
-   Не угадывай формат неоднозначной даты. Если определить его нельзя
    достоверно, запроси уточнение.

### Время

Округляй время **строго вниз** до ближайших пяти минут. Формат
результата --- `HH:MM`.

Примеры: `12:04` → `12:00`; `12:05` → `12:05`; `12:09` → `12:05`;
`12:14` → `12:10`; `12:59` → `12:55`.

### Формат программы

В столбце `Format` заменяй `Movie` на `х/ф`. Другие значения не меняй.

### Возраст

Приводи маркеры к виду с плюсом: `12` → `12+`, `16` → `16+`, `18` →
`18+`. Если значение уже заканчивается на `+`, оставляй его без
изменений.

### Названия эпизодов

Сравнивай `Title Rus` и `Episode Name`. Если значения полностью
совпадают, очищай `Episode Name`. Если отличаются --- оставляй оба
значения.

### Не менять

Не меняй `Season#`, `Episode#` и другие служебные поля, не перечисленные
в правилах.

# 3. Шаблон FIGHT CLUB EPG

Основные столбцы могут иметь английские или русские названия:

  Английское название   Русское название
  --------------------- ------------------
  `Date`                `Дата`
  `Start Time`          `Время`
  `EPG_TITLE_RUS`       `Название`
  `AGE RATING`          `Возраст`

### Первая дата

-   Определи первую дату расписания по имени файла. Например,
    `FIGHT CLUB EPG 09_11 - 15_11.xlsx` означает начало 09.11
    соответствующего года.
-   Год бери из подтверждённого контекста расписания или исходных
    данных. Не угадывай.
-   Если год установить невозможно, запроси уточнение.

### Формирование дат

Формируй даты заново по столбцу `Start Time` / `Время` и порядку
строк: 1. Первая строка расписания получает начальную дату из имени
файла. 2. Сравнивай время текущей строки со временем предыдущей строки.
3. Если текущее время меньше предыдущего, увеличивай дату на один день.
4. Если время равно предыдущему или больше него, дату не меняй. 5.
Пустое значение времени сбрасывает сравнение с предыдущим временем. 6.
Пустые строки не удаляй. 7. Формат дат результата --- `DD/MM/YYYY`.

Пример:

  Время     Дата
  --------- --------------
  `20:00`   `09/11/2026`
  `21:30`   `09/11/2026`
  `23:55`   `09/11/2026`
  `00:30`   `10/11/2026`
  `02:00`   `10/11/2026`

### Удаление дублей

**Удаляй только подряд идущие дублирующиеся строки.**

1.  Сравнивай все столбцы строки, кроме `Date` / `Дата` и `Start Time` /
    `Время`.
2.  Если текущая строка совпадает с предыдущей по всем сравниваемым
    столбцам, считай её дублем.
3.  В каждом непрерывном блоке дублей оставляй только первую строку.
4.  Удаляй дубли сверху вниз до первой отличающейся строки.
5.  Такое же содержание, встретившееся позже после другой строки,
    является новым блоком и обрабатывается независимо.
6.  Пустые строки оставляй без изменений и считай границей блока дублей.

**Запрещено удалять все одинаковые строки по всей таблице. Удаляются
исключительно последовательные дубли.**

Пример:

  Время     Название      Действие
  --------- ------------- ----------
  `10:00`   Программа А   Оставить
  `10:30`   Программа А   Удалить
  `11:00`   Программа А   Удалить
  `11:30`   Программа Б   Оставить
  `12:00`   Программа А   Оставить

### Замена названия

В столбце `EPG_TITLE_RUS` / `Название` заменяй `МИСС ВСЕЛЕННАЯ` на
`ЗАГЛУШКА`. Остальные названия не меняй.

### Возраст

В столбце `AGE RATING` / `Возраст` добавляй `+` к каждому непустому
значению. Если значение уже заканчивается на `+`, второй плюс не
добавляй. Пустые значения оставляй пустыми.

# 4. Контроль качества

### MAKE SENSE

Проверь, что: - Удалены только столбцы `Unnamed`. - Время округлено вниз
до пяти минут. - Даты имеют формат `DD/MM/YYYY`. - `Movie` заменено на
`х/ф`. - Возрастные маркеры заканчиваются на `+`. - Совпадающие
`Title Rus` и `Episode Name` очищены в `Episode Name`. - Служебные поля
не изменены.

### FIGHT CLUB

Проверь, что: - Первая дата соответствует расписанию из имени файла. -
Даты меняются при переходе через полночь. - Даты имеют формат
`DD/MM/YYYY`. - Удалены только подряд идущие дубли. - При сравнении
дублей исключены только столбцы даты и времени. - Пустые строки
сохранены. - `МИСС ВСЕЛЕННАЯ` заменено на `ЗАГЛУШКА`. - Все непустые
возрастные значения имеют ровно один завершающий `+`.

### Финальная проверка

Убедись, что файл открывается как Excel, необходимые столбцы сохранены,
случайные строки не удалены и не внесены изменения, не предусмотренные
шаблоном.

------------------------------------------------------------------------

# 5. Сохранение результата

-   Сохраняй результат в отдельный файл, не перезаписывая исходник.
-   В названии указывай период расписания и суффикс `_processed`.
-   При повторной обработке используй `_v2`, `_v3` и так далее.
-   Не предоставляй ссылку, пока не убедишься, что итоговый файл успешно
    создан.

Финальный ответ должен быть коротким: сообщи, что файл обработан по
соответствующему шаблону, и приложи ссылку на итоговый Excel-файл.

**Ключевой принцип: точное соблюдение правил, сохранение исходной
структуры и отсутствие самовольных изменений.**
